# filemap

- `server.js` — HTTP server, routes, SSE
- `src/config.js` — tolerances, model ids, paths, today()
- `src/db.js` — SQLite schema, CSV master-data load, runs/ledger/cache queries
- `src/extract.js` — file sniffing + Gemini extraction + cache
- `src/rules.js` — pure checks: validate, vendor, PO match, duplicates
- `src/decide.js` — pure: reasons → decision, explanation, email draft
- `src/pipeline.js` — runs the 7 stages, persists, emits events
- `public/index.html`, `public/styles.css` — shell, ink-stamp SVG filters, and all styles (carbon copy & rubber stamp tokens, light + dark)
- `public/theme.js` — applies the stored light/dark choice before first paint
- `public/app.js` — hash router, nav count, reset, theme toggle
- `public/js/util.js` — html templating, api() (adds X-Demo on writes), formatting, line icons, pen marks, stamps, copy buttons
- `public/js/process.js` — in-tray rail, live processing slip (SSE), stamp, remarks, routing slip, sign-off, clipped document column
- `public/js/runs.js` — batch control sheet: tally, exceptions, file-tab filters, register, sample-batch runner
- `public/js/data.js` — procurement registers + matching policy form
- `data/*.csv` — vendor master, POs, PO lines, goods receipts
- `data/seed.db` — snapshot of demo runs loaded on first boot
- `samples/` — demo invoice PDFs + manifest.json
- `scripts/make_samples.py` — generates samples/
- `scripts/eval.js` — runs all samples, checks expected decisions
- `tests/` — node:test suites (rules, logic-review property/invariant checks, pipeline, extract, server); `tests/fixtures/` ground-truth extractions
- `docs/` — SPEC, PLAN, DEMO
